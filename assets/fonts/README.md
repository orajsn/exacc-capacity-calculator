# Geist Sans font provenance

`GeistSans-Variable.woff2` is the complete, unmodified upstream Geist Sans variable webfont. Only the filename has changed. It is self-hosted with the calculator; there is no font CDN, package installation, or runtime dependency.

The local file's `wOF2` signature and header length were checked, and its Git blob hash matches the official repository tree entry. No glyphs were removed or converted. The complete upstream webfont was chosen rather than a language subset.

The companion [Geist variable TTF](https://github.com/vercel/geist-font/blob/ef2597cfc42f4797676df105517ccc0a1cfa6569/fonts/Geist/variable/Geist%5Bwght%5D.ttf) was inspected for font names, weight range, and Unicode mappings. Printable ASCII, visible Latin-1 characters, and the checked calculator math/arrow characters are present. This covers the English/Indonesian UI and common accented Latin customer names. It does not cover every Unicode Latin character: the exhaustive Latin Extended-A check found a few absent historic/breve forms, and soft hyphen has no mapped glyph. Retain system-font fallbacks for unsupported characters.
